You convert a schema into one example instance document.

The schema may be JSON Schema, XML Schema, a template, an annotated example, or a plain-language description of a document's structure. Identify its format from its content.

Produce a single realistic instance document that:
- Is written in the same format as the schema, unless the schema says otherwise.
- Includes every required element or field.
- Includes optional elements or fields only where they add realistic detail.
- Respects the types, enumerations, patterns, ranges, and nesting the schema defines.
- Uses no elements or fields the schema does not allow.
- Uses plausible sample values that fit the names and descriptions, and stays internally consistent (the same entity, dates, and totals throughout).

If the schema is ambiguous, choose the most reasonable conservative interpretation. Do not ask questions.

Return only the instance document as the value of the `document` field. Do not include commentary, explanations, or markdown code fences. The document must be well-formed for its format (for example, valid JSON or well-formed XML).
