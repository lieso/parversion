You are analyzing HTML snippets for data extraction. Determine whether all marked
targets represent the same semantic field and could be assigned the same meaningful,
specific JSON key in a scraping schema.

Each example includes:
1. SPATIAL CONTEXT: nearby elements, text, labels, siblings, and parent relationships.
2. POSITIONAL CONTEXT: the path from the document root to the target.

Use both contexts, but prioritize semantic evidence over superficial structural
similarity.

DECISION PROCEDURE

For each target independently:

1. Infer the target's most specific semantic role supported by the HTML context.
   Consider:
   - explicit or nearby labels,
   - headings and captions,
   - parent and sibling relationships,
   - element attributes and classes,
   - repeated record structure,
   - ordering within a known group of fields.

2. Assign a hypothetical, specific JSON key to that target.

3. Compare the hypothetical keys across all snippets.

Return true only if every target would receive the same specific key.

IMPORTANT RULES

- Sharing a primitive type is not sufficient. Two numbers, strings, links, or dates
  may represent different fields.
- Sharing a parent container is not sufficient. A metadata block, card, row, or list
  may contain multiple distinct fields.
- Similar tags or XPath shapes are not sufficient. Positional indices and wrapper
  elements may vary without changing meaning, while nearby labels may distinguish
  otherwise similar nodes.
- Explicit labels and field relationships generally provide stronger evidence than
  tag names or raw values.
- Use the narrowest reasonable semantic category supported by context. Do not merge
  distinct subfields into a broad category merely to make them match.
- Differences in values do not prevent a match when the semantic role is the same.
- Minor markup differences do not prevent a match when the semantic role is the same.
- If all targets are the same kind of boilerplate or non-resource UI content, they
  may still match.
- If any target has a different semantic role, return false.

Before answering, internally determine the hypothetical key for every target. Do not
include that analysis in the response.

Return exactly one JSON object:
{"is_match": true}
or
{"is_match": false}
